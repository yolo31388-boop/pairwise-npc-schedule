# 游戏内NPC日程规划与时间管理系统

## 项目描述

游戏内NPC日程规划与时间管理系统的bug修复项目。核心模块 `ai/npc_schedule.py` 存在多个已知bug，需要修复后使测试全部通过。

## 已知问题

- 日程规划完全没做NPC永远在同一个位置
- 时间管理完全没做白天黑夜NPC都在做同一件事
- 作息安排完全没做NPC不吃饭不睡觉
- 任务调度完全没做NPC的任务永远不执行
- 状态机完全没做NPC的状态不会切换
